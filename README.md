# Entre Senderos

Sitio web en español para explorar talleres de escritura, consultar próximas ediciones y descubrir publicaciones de la comunidad.

## Funcionalidades

- Catálogo de talleres y servicios con páginas de detalle.
- Ediciones independientes y calendario de actividades.
- Blog con etiquetas, paginación y créditos de autoría.
- Formularios de contacto, inscripción y suscripción.
- Administración de contenidos.
- Diseño adaptable a móviles, tabletas y computadoras.

## Desarrollo local

```powershell
npm ci
npm test
npm run build
```

La vista previa se puede servir con un servidor estático local. Utiliza únicamente datos ficticios durante el desarrollo.
